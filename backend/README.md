# Health Prediction Application

## Overview

This project is a Health Prediction Application developed using React.js, Flask, and SQLite.

The application allows users to manage patient records and predicts possible health conditions based on blood test values.

## Features

* Create Patient Records
* View Patient Records
* Update Patient Records
* Delete Patient Records
* Health Risk Prediction
* Email Validation
* Date of Birth Validation
* Persistent Data Storage using SQLite

## Technologies Used

### Frontend

* React.js
* Axios

### Backend

* Python Flask
* Flask SQLAlchemy
* Flask CORS

### Database

* SQLite

## Health Prediction Logic

The application predicts possible health conditions based on:

* Glucose
* Haemoglobin
* Cholesterol

Example predictions:

* High Risk of Diabetes
* High Cholesterol Risk
* Possible Anemia
* Normal

## Validation Implemented

* Email format validation
* Date of Birth cannot be a future date
* Mandatory field validation
* Numeric validation for blood test values

## CRUD Operations

* Create Patient
* Read Patient
* Update Patient
* Delete Patient
